# Models Directory (دليل مجلد النماذج)

ضع ملفات نماذج الذكاء الاصطناعي بصيغة `.gguf` هنا:

## النموذج الموصى به:
- **Gemma-4-E2B-it (Quantized Q4_K_M)**
- اسم الملف: `gemma-4-E2B-it-Q4_K_M.gguf`
- رابط التحميل من Hugging Face:
  `https://huggingface.co/google/gemma-2-2b-it-GGUF` أو مستودعات `Gemma-4` الرسمية.

## تشغيل الموديل:
- على **Windows**: انقر مرتين على `run-local-gemma.bat`.
- على **Linux**: شغل `./run-local-gemma.sh` أو استخدم `systemctl --user start neural-llama.service`.
