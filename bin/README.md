# Bin Directory (دليل برمجيات التشغيل)

ضع ملف تشغيل `llama-server` هنا إذا لم يكن مثبتاً في نظامك:

- لمستخدمي **Windows**: ضع ملف `llama-server.exe` مع ملفات `cudart` أو `vulkan` هنا.
- لمستخدمي **Linux**: ضع الملف التنفيذي `llama-server` هنا.

رابط تنزيل أحدث إصدار مجمع جاهز من llama.cpp:
https://github.com/ggerganov/llama.cpp/releases
