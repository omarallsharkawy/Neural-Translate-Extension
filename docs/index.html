01

تشغيل محرك الذكاء الاصطناعي المحلي (Gemma-4 على الـ GPU)

تتيح الإضافة تشغيل نموذج Gemma-4 فائق الذكاء محلياً بالكامل على جهازك عبر خادم الاستدلال المباشر llama-server على المنفذ 28491. يعمل المحرك كخدمة خلفية خفيفة على كارت الشاشة (Nvidia GPU عبر تسريع Vulkan أو CUDA) لأي بطاقة رسوميات حديثة بذاكرة تبدأ من 3 جيجابايت VRAM، مما يوفر ترجمة فورية في أقل من نصف ثانية دون استهلاك أي إنترنت أو إرسال بياناتك لخوادم خارجية.

معمارية الاستدلال المحلي المستقل (Standalone Local AI Architecture)

يتميز المحرك المحلي بالاستقلالية التامة والخصوصية المطلقة (Zero Data Telemetry)، حيث تتم معالجة وتجزئة وترجمة كافة النصوص مباشرة داخل ذاكرة بطاقة الرسوميات بجهازك (VRAM) مع نافذة سياق ضخمة 32K توكن واستدلال مزدوج متوازٍ.

أوامر التحكم في خدمة الموديل المحلي من الطرفية:

# التحقق من حالة الموديل واستهلاك الـ VRAM
systemctl --user status neural-llama.service

# إعادة تشغيل خدمة الموديل
systemctl --user restart neural-llama.service

# إيقاف خدمة الموديل
systemctl --user stop neural-llama.service

# بدء خدمة الموديل
systemctl --user start neural-llama.service

دليل تشغيل Gemma-4 على نظام ويندوز (Windows Setup Guide)

إذا كنت تستخدم نظام Windows وتريد تشغيل الموديل محلياً على جهازك دون إنترنت:

  1. تحميل ملف السيرفر: قم بتنزيل llama-server.exe (من إصدارات llama.cpp الرسمية مع دعم Vulkan أو CUDA) وضعه داخل مجلد bin/ في المشروع.
  2. تحميل ملف الموديل: قم بتنزيل ملف الموديل بصيغة GGUF (مثلاً gemma-4-E2B-it-Q4_K_M.gguf) وضعه داخل مجلد models/.
  3. بدء التشغيل: انقر مرتين على ملف run-local-gemma.bat الموجود في المجلد الرئيسي للإضافة.
  4. سيبدأ السيرفر فورياً على المنفذ 28491، وستتعرف عليه الإضافة تلقائياً.

* بديل أسهل بنقرة واحدة على ويندوز: يمكنك فتح برنامج LM Studio أو Ollama وتشغيل أي موديل، ثم فتح إعدادات الإضافة واختيار القالب الجاهز لـ LM Studio أو Ollama.

فحص نقطة النهاية المباشرة للتأكد من استجابة السيرفر المحلي:

curl -s http://127.0.0.1:28491/health
02

ربط مزودات الذكاء الاصطناعي السحابية (Custom APIs)

تدعم الإضافة الاتصال المباشر بأي موديل سحابي ذكي فائق السرعة عبر واجهات OpenAI-compatible أو Anthropic Messages.

  • DeepSeek: رابط النهاية https://api.deepseek.com/v1/chat/completions مع موديل deepseek-chat.
  • GLM (Zhipu AI): رابط النهاية https://open.bigmodel.cn/api/paas/v4/chat/completions مع موديل glm-4-flash.
  • OpenRouter: رابط النهاية https://openrouter.ai/api/v1/chat/completions لأي موديل مفتوح.
  • OpenAI: موديلات gpt-4o-mini وغيرها.
  • Anthropic: رابط النهاية https://api.anthropic.com/v1/messages مع موديل claude-3-5-haiku-20241022.

طريقة الضبط:

  1. اضغط على أيقونة الإضافة في شريط المتصفح، ثم انقر على أيقونة الإعدادات في الزاوية.
  2. انقر على اسم المزود من الأزرار الجاهزة (مثل DeepSeek أو GLM).
  3. الصق مفتاحك الخاص في خانة API Key.
  4. اضغط زر "اختبار الاتصال" للتحقق من زمن الاستجابة بالميلي ثانية ثم اضغط "حفظ الإعدادات".
03

قائمة الزر الأيمن المتكاملة (Right-Click Context Menu)

توفر الإضافة قائمة سريعة متكاملة تظهر مباشرة عند النقر بالزر الأيمن في أي مكان على الصفحة دون الحاجة لحفظ أو تذكر أي اختصارات:

  • ترجمة كامل الصفحة (مع استمرار التلقائي عند التمرير والروابط): تترجم الصفحة بالكامل فورياً وتفعل الترجمة التلقائية المستمرة أثناء التمرير ونزولك لأسفل الصفحة والتنقل بين الصفحات والروابط.
  • ترجمة هذه المنطقة / الفقرة المحددة فقط في مكانها: انقر بزر الماوس الأيمن على أي فقرة أو مقال أو كارت محدد لترجمته هو فقط مكانه دون المساس بباقي الصفحة.
  • تشغيل/إيقاف الترجمة التلقائية لهذا الموقع دائماً: لتثبيت النطاق أو إيقاف المتابعة التلقائية بنقرة واحدة.
  • استبدال النص المحدد بمكانه مباشرة: عند تحديد أي جملة، يستبدلها بالنص العربي فوراً داخل سياقها.
  • ترجمة النص المحدد في النافذة العائمة: يعرض بطاقة المعاينة والخيارات فوق التحديد.
  • استعادة النصوص الأصلية للصفحة (Revert): لإرجاع كافة النصوص إلى حالتها الأصلية بلمسة واحدة.
  • فتح قارئ ومترجم المستندات (PDF / Word / EPUB): لفتح بيئة قراءة الكتب والمستندات الطويلة.
03

الترجمة التلقائية المستمرة للمواقع (Dynamic Continuous Auto-Translate)

خاصية مصممة خصيصاً للمواقع ذات التمرير اللانهائي (Infinite Scroll) والمواقع المبنية بأطر العمل الحديثة (React و Next.js و Vue ومواقع التوثيق التقني):

  • ترجمة تلقائية مستمرة للنطاق: عند تفعيل خيار "الترجمة التلقائية المستمرة لهذا الموقع"، يتم حفظ النطاق في الذاكرة الدائمة. بمجرد فتح أي صفحة تابعة لنفس الموقع، تبدأ الترجمة فوراً وتلقائياً.
  • مراقب المحتوى الحي (MutationObserver): عند النزول بالماوس لأسفل وتحميل فقرات جديدة، تلتقط الإضافة العناصر المضافة فوراً وتترجمها في الخلفية دون الحاجة للنقر على أي زر.
  • رصد التنقل الداخلي (SPA Route Changes): عند الضغط على أي رابط فرعي أو قائمة داخلية دون إعادة تحميل الصفحة بالكامل، تكتشف الإضافة تغيير المسار وتترجم الصفحة الجديدة مباشرة.
04

الاختصارات ولوحة المفاتيح

تم تعزيز استجابة الاختصارات لتعمل بدقة متناهية وبدعم كامل لكلا اللغتين العربية والإنجليزية على لوحة المفاتيح:

الاختصار الوظيفة التوافق
Alt + Shift + T أو Alt + Shift + ف ترجمة كامل نصوص الصفحة الحالية فورياً أو استعادتها أي موقع ويب
Alt + Shift + R أو Alt + Shift + ق فتح مساحة عمل قارئ ومترجم الكتب (Neural Reader) في تبويب جديد في أي مكان
Escape (Esc) إغلاق النوافذ المنبثقة والكبسولة واسترجاع النص الأصلي تفاعلي
05

قارئ ومترجم الكتب والمستندات (Neural Reader)

مساحة عمل مخصصة للمستندات الطويلة (مئات الصفحات) تدعم السحب والإفلات وقراءة وتجزئة الصيغ التالية محلياً بدون خوادم وسيطة:

  • ملفات PDF (.pdf): استخراج النصوص الرقمية وإعادة تركيب الفقرات بذكاء عبر محرك PDF.js المدمج.
  • مستندات Word (.docx): تحليل عناصر XML والفقرات والعناوين دون الحاجة لحزمة Office.
  • كتب EPUB (.epub): استخراج فصول الكتاب كنصوص مرتبة بالكامل.
  • ملفات Markdown و TXT (.md, .txt): معالجة فورية وتجزئة ذكية للفقرات.

خيارات العرض والتصدير:

  • العرض المزدوج (Dual-Pane): النص الأصلي يساراً والنص المترجم يميناً مع تمرير وتظليل متزامن ونحاسي.
  • التدفق المترجم (Inline): عمود قراءة مستمر مع قائمة طي (details) أسفل كل فقرة للاطلاع على النص الأصلي عند الحاجة.
  • قائمة التصدير: نسخ الترجمة كاملة بنقرة واحدة للحافظة (Clipboard) أو تحميلها بصيغة Markdown أو TXT.

التجميع والرفع لـ GitHub و Chrome Web Store

تم إعداد سكربت تجميع أوتوماتيكي يقوم بفحص الكود، ضغط الأصول، وإنتاج حزمة ZIP نهائية ومحكمة: 

# تشغيل سكربت التجميع
./package.sh

# الملف الناتج في المجلد
dist/neural-translate-v1.0.2.zip

طريقة التثبيت في متصفح Brave أو Chromium:

  1. توجه إلى brave://extensions وفعل Developer mode.
  2. اضغط على Load unpacked واختر مجلد المشروع:
    /home/omar/Projects/translation extntion
  3. أو يمكنك رفع ملف dist/neural-translate-v1.0.2.zip مباشرة إلى متجر Chrome Web Store للمطورين.
